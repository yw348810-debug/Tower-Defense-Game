海克斯塔防 / Hex Defense
Windows 64 位试玩版

【启动】
1. 将 ZIP 完整解压到一个文件夹。
2. 双击 TowerDefense.exe 启动。
3. 保留同目录下的 TowerDefense_Data、DLL 和其他随包文件。
无需安装 Unity、Python 或开发工具。

【开始试玩】
首页点击“开始游戏”，选择三个关卡之一。
初次体验可在设置中选择“简单”；“困难”保留原始经济与敌人数值。
希望快速查看各种单位与法术，可选择“作弊”模式，资源显示为 ∞。
设置支持音量、中英双语和难度调整，选择会自动保存。
开局选一张海克斯卡后，敌人开始进攻。

【操作】
鼠标左键：选择塔种、塔位、按钮，以及确认法术目标位置。
鼠标右键：取消法术瞄准。
1～5：选择当前关卡已开放的塔种。
Q：瞄准火球。
E：瞄准冰霜法术，第二关起开放。
R：瞄准援军位置，第三关开放。
F：施放全军战吼，第三关开放。
Esc：打开或关闭暂停菜单，可进入设置或返回首页。

先选择塔种，再点击地图上的圆形塔位和“建造”。
选中已建造的塔后可升级，每座塔最高三级。
第二关起，法术也可使用金币升级至三级。
点击“暂停/继续”调整战斗状态，点击“1x/2x”切换速度。
普通暂停时仍可规划建造与升级，暂停时不能施法。

【海克斯与胜负】
本作包含三关、五类塔、四种法术和 54 张海克斯卡。
各关卡逐步开放更多单位、法术与强化品质。
每轮三选一时，每个卡位均可免费刷新一次，刷新保持原品质。
选定强化持续本局，重新开始时重置。
进度条到末尾后，还需要消灭剩余敌人才能获胜。
基地生命降至 0 时失败；可以重开当前关卡。
