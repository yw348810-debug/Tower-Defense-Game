# 第一关海克斯与挑战难度

2026-10-15 部署记录。第一关部署银色和金色各 10 张，每次随机展示三张并选一张。开局银色，第四阶段开始前金色；本关最多两张。第二关已部署银 / 金 / 彩各 11 张，详见 [第二关说明](Second-Level-Gameplay.md)。第一关不抽取彩色与兵营牌。

选择期间停止敌人、弹体、法术、出怪计时和玩家购买，选完恢复原来的游戏速度。效果只在本局有效，重开清空。每次候选同品质且不重复，至少包含一张通用卡，中期排除完全无法生效的条件卡。

## 难度起始配置

- 开局金币 220 → 180；生命 20，魔法值 0。
- 普通 / 快速 / 重甲敌人血量 50 / 34 / 300 → 54 / 38 / 330；移动速度、击杀收益、重甲抗性保持原值。
- 阶段开始时间为 0 / 24 / 48 / 72 / 96 / 120 / 144 秒；敌人成对生成间隔缩短 10%，相当于批次内生成速率提高约 11%。
- 第一关仍为 156 个敌人，最后一批约在 154.4 秒生成。进度结束后清理存活敌人才会胜利。
- 火球保持 12 魔法值、半径 3.2、基础 3 秒燃烧、每 0.5 秒 10 伤害；卡牌可以改变持续时间和互动。

## 编辑器检验

打开 Level01_ForestOutpost，进入 Play Mode，开局应显示三张银色卡。选完才允许建塔并开始计时，72 秒时显示三张金色卡。顶部显示已选卡，悬停查看说明；重开重新抽取。保持原先英文 TMP 字体，避免中文缺字。
