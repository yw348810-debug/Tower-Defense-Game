# 海克斯重设计

银色、金色、彩色各 18 张，共 54 张。每局依旧三选一，每张牌独立刷新一次。第一关只抽银、金；第二关解锁兵营、冰霜与法术升级；第三关增加援军、战吼与增益塔。候选同时检查具体塔/法术是否能使用，避免满地图时抽到没有作用的牌。

组合示例：

- **寒霜 → 蒸汽**：霜冻电池积攒魔法，蒸汽回路将冰火交汇变成伤害与魔法值，元素沸腾扩大爆炸，第三关三相共鸣再接增益塔易伤。
- **军团围城**：英雄壁垒维持阻拦，围城阵列提高炮击伤害；不灭军团和圣所反应堆提供续航，爆裂遗志、凤凰契约让牺牲也能反击。
- **满级法师防线**：精工准星强化三级塔，法术启蒙、奥术投资让升级转为魔法；升级接力与杰作共振连起施法、攻速，奥术统治强化满级法术。
- **薪火经济**：余烬账本与薪火收割将燃烧击杀变为双资源，烈焰红利支持升级；双重陨火复制燃烧，复制不会触发施法返还，避免无限循环。

移出候选池：应急护盾、魔力储备、重装猎手、兵种专精、战地医疗、孤胆守卫、背水一战。原 enum ID 保留，兼容旧验证工具；不会被随机抽取。

## 触发边界

伤害最终由 EnemyAgent 统一结算护甲与最强易伤。次级爆炸、穿透伤害、复制火球不调用普通攻击/手动施法触发器；蒸汽、共鸣使用 SpawnVersion 冷却，不会继承对象池前一次生命的触发状态。军团死亡收益仅由真实战斗死亡触发，法术到期和重开不触发。数值返还按照实际升级支付金额，免费改造返还零。所有每秒收益有上限，重开清理计数和冷却。首领冻结沿用现有控制抗性。
