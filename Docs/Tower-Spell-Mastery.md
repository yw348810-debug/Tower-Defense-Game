# 三级塔与法术强化

本轮沿用现有三张地图和 UI。第一关保持基础火球；第二关开放火球和冰霜升级；第三关保留全部四种法术。法术每局从一级开始，购买两次升级到三级，重开重置。费用仍使用金币，施放仍消耗魔法值。

## 三级塔

| 塔 | 满级能力 | 表现 |
| --- | --- | --- |
| 速射塔 | 主目标完整伤害；1.25 米内其他敌人受到45%溅射 | 双金色弹道、爆裂火花和冲击环 |
| 寒冰塔 | 1.7 米小范围伤害与减速；邻近目标受到65%伤害；冻结1秒 | 大型冰晶炮弹、碎晶与冰爆环 |
| 爆破塔 | 3.2 米基础爆炸；碎冰64伤害、4米范围 | 熔核重弹、弧线轨迹、烟尘与多重冲击环 |
| 兵营 | 三名士兵180生命/24攻击；英雄520生命/52攻击，每第三击对附近其他敌人旋风斩，造成60%伤害 | 金色精锐装备；英雄独立模型和金色旋风冲击 |
| 增益塔 | 38%易伤，离开后最多3秒；友军每秒恢复22生命 | 翡翠符文、光柱与脉冲；有效作用时每2秒最多播放一次 |

寒冰塔之间共享每个敌人的3秒再次冻结间隔；Boss保留控制抗性。炮塔范围伤害、英雄旋风斩与海克斯次级伤害不会递归产生攻击。高级视觉不改变弹体的真实命中时间。

## 法术升级与高级援军

| 法术 | 一级→二级金币 | 二级→三级金币 | 满级区分 |
| --- | ---: | ---: | --- |
| 火球 | 80 | 140 | 更大陨石与火焰尾迹、密集火星、焦土与强烈冲击；范围、灼烧时长与每次伤害提高 |
| 冰霜 | 90 | 150 | 独立符文圈、更多大型冰晶；范围与冻结时长提高 |
| 援军 | 90 | 150 | 黄金召唤仪式；独立英雄模型率领四名精锐护卫 |
| 战吼 | 100 | 160 | 友军身上的多层符文与光柱；持续时间、攻击、攻速与范围提高 |

一级援军：3名新兵，120生命/14攻击，驻留18秒。二级：4名老兵，170生命/20攻击，驻留22秒。三级：1名英雄（420生命/44攻击）与4名精锐（230生命/28攻击），驻留26秒。英雄可阻挡两个敌人并旋风斩；护卫增加装备。援军自然到期不会触发死亡奖励。

海克斯可进一步改变以上数值。54张海克斯和组合方向见 [Augment-Rework.md](Augment-Rework.md)。
