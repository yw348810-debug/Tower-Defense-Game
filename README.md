# 海克斯塔防 / Hex Defense

单人 Unity 客户端 / Gameplay 求职 Demo。Unity 6000.6.3f1，URP 17.6，新 Input System。

## 下载试玩

Windows 64 位试玩包在 [GitHub Releases](https://github.com/yw348810-debug/Tower-Defense-Game/releases) 发布。下载附件中名称带 `Windows-x64` 的 ZIP，完整解压后双击 `TowerDefense.exe`。请保留同目录下的 `TowerDefense_Data`、DLL 和其他随包文件，无需安装 Unity 或 Python。Release 自动生成的 `Source code` 压缩包是工程源码；可运行试玩包由发行附件单独提供。

首页支持开始游戏、选择三个独立关卡、设置和退出。设置含音量、中英双语及简单 / 困难 / 作弊三档难度，选择会保存并应用于当前战斗。困难保留原始平衡；简单开局金币 +80%、基地生命翻倍，敌人生命 / 速度 / 近战伤害分别为原值的 55% / 80% / 65%，击杀奖励提高。作弊模式金币、生命和魔法值不可耗尽，显示为 ∞。

三关每次海克斯选择时，每张卡都可免费刷新一次，刷新保持本轮品质。当前银色、金色、彩色海克斯各 18 张，共 54 张，按关卡解锁和当前阵容过滤候选，带中英双语说明与联动提示。冰火蒸汽、兵营炮击、升级魔法回流、满级塔共振与召唤军团可组合成不同打法，完整卡池见 [海克斯重设计](Docs/Augment-Rework.md)。

地图已加入分区地形、路缘、塔位石台和主题地标；攻击与法术使用有数量上限的特效池，三级塔和三级法术有更强的弹体、命中与范围表现。UI 加入统一面板、属性色、交互反馈与清晰中文字体。实现与编辑说明见 [画面打磨说明](Docs/Art-Polish.md)。

主页、森林、峡谷和雪地各有一段原创循环配乐，切换场景时自动淡化。25种音效覆盖菜单、建造升级、海克斯、塔攻击与命中、四种法术、友军战斗、波次、Boss、基地受击及胜败。首页和战斗设置中的同一音量滑块实时控制全部声音，0为静音，设置自动保存；暂停时战斗音效暂停，背景音乐和菜单音继续。素材来源与再生成方式见 [音频资产](Docs/Audio-Assets.md)。

## 当前可玩内容

第一关「林间哨站」已实现双入口合流、3.4米宽的双列道路、6 个固定塔位、三种塔与两次升级、魔法值和火球法术、三种带行走动画的敌人、七阶段连续进攻、金币、基地生命、暂停倍速、胜败与重开。开局银色、中期金色，各三选一，仅抽取本关可使用的卡牌，彩色与后续关卡专用机制锁定。开局选完后自动出怪，中期选择暂停整个战场。全场 156 个敌人，敌人按左右两列成对生成，最后一个约在 154.4 秒生成，之后消灭存活敌人才会胜利。

第二关「岩谷汇流」使用第二张独立地图：8 个塔位、四种塔、兵营小兵与独立模型英雄、六类敌人、12 波共 348 个敌人、三次银 / 金 / 彩海克斯选择，以及冰霜法术。从第二关起开放金币升级法术，火球与冰霜均可升级两次、最高三级。

第三关「核心要塞」使用第三张雪地地图：10 个塔位、五种塔、四种法术、18 波共 552 个敌人。新增易伤与治疗增益塔、临时援军和全军战吼，四种法术均可花金币升到三级。援军一级召唤新兵、二级召唤老兵，三级为四名老兵加一名使用独立英雄模型的冠军，冠军具有更高生命、伤害和旋风斩。三次海克斯选择中，每个卡位各可免费刷新一次。第 6 波雪原守卫、第 18 波冬境泰坦采用独立大体型模型，带控制抗性与残血狂暴。三关各用自己的地图与数值，通关后按顺序前进。第三关原始配置见 [第三关说明](Docs/Third-Level-Gameplay.md)，当前海克斯配置以重设计文档为准。

## 运行与操作

- Unity：进入 Play Mode 从首页开始，点击开始游戏后选择关卡；编辑器已配置 `MainMenu` 为播放起始场景。
- 第二关困难模式初始 240 金币、20 生命、0 魔法值。详细兵营、出怪和彩色卡配置见 [第二关说明](Docs/Second-Level-Gameplay.md)。
- 第三关困难模式初始 400 金币、25 生命、0 魔法值；18 波从 0 至 340 秒连续开始。首领清理完毕才会胜利。
- 可在 Unity 的 `Tools > Tower Defense > Build Windows Demo` 构建当前首页与三关的 Windows 64 位版本，默认输出到 `Builds/WindowsDemo`。试玩说明在 `Docs/Windows-Player-Readme.txt`；用 `Tools/Build/Package-WindowsDemo.ps1` 为构建目录附加说明与授权并生成 ZIP。
- 左下选择塔种，点击地图上的圆形塔位，再点 `BUILD`。已建塔再次选中可点 `UPGRADE`，每塔可升级两次，从 LV 1 到 LV 3，逐级切换外观。
- 第一关困难模式初始 180 金币、20 点生命、0 点魔法值。金币靠击杀获得；建造和升级在进攻期间均可进行，普通暂停时也可规划并购买，选牌期间锁定操作。
- 第一关开局显示三张银色卡，选择一张后开始；战斗时间 72 秒、重甲进攻前显示三张金色卡。效果持续本局，重开重新抽取；顶部卡牌悬停可查看完整说明。彩色第一关锁定，第二、三关依次选择银 / 金 / 彩；当前 54 张完整说明与组合示例见 [海克斯重设计](Docs/Augment-Rework.md)。
- 七阶段开始时间为 0 / 24 / 48 / 72 / 96 / 120 / 144 秒，批次内出怪间隔缩短 10%，敌人血量提高。升级和施法的时机更重要。
- `PAUSE / RESUME` 暂停和恢复，`1x / 2x` 调整速度；`Esc` 打开暂停菜单，可进入设置或返回首页。`1`–`5` 选择本关已解锁的塔种。
- 点击 FIREBALL 卡或按 Q 进入施法瞄准，橙色范围圈跟随鼠标，左键点击地图施放；右键取消。每次消耗 12 魔法值，半径 3.2，落地后持续燃烧 3 秒，每 0.5 秒造成一次 10 点伤害，共 6 次。敌人离开圆圈后不再受伤；可连续施放和叠加多个火球。暂停时不施法。
- 第二关点击 FROST NOVA 卡或按 E 瞄准冰霜法术：18 魔法值、半径 3.8、冻结 3.5 秒、冷却 10 秒。冻结期间敌人停止移动和近战，暂停与选牌也暂停冷却。
- 第二关起，法术卡上的升级按钮使用金币，每种最多升级两次；第一关法术保持一级。战地工坊同时降低塔与法术升级费用，法术启蒙和奥术投资可把升级转化为魔法值。
- 第三关按 R 或点击 REINFORCE，在地图选择位置，援军落在附近道路；按 F 或点击 BATTLECRY，立即强化全部塔与友军。援军升级改变队伍构成与模型，火球、冰霜、援军和战吼的三级表现均区别于一级。
- 三关选牌期间，每张卡下方都有独立 REFRESH 按钮。刷新不消耗金币，每个卡位每轮一次；第一关两轮最多 6 次，第二、三关三轮最多 9 次。刷新保持同一品质且当前三个候选不重复。
- 顶部进度条表示整场出怪时间，旗标表示下一阶段开始时刻；进度到末尾后，剩余敌人仍须清理。
- 守住最终进攻进入胜利结算，生命为零失败；`PLAY AGAIN` 从第一阶段、初始经济重新开始。

## 实现结构

- `LevelMap / EnemyRoute / BuildSlot`：地图、独立完整路径、塔位数据。
- `LevelSession`：绝对时间线、金币 / 魔法值、升级与法术、按敌种独立的对象池、弹体和命中特效池、胜败与重开。
- `AugmentCatalog / AugmentDefinition / AugmentState`：银 / 金 / 彩各18张、共54张候选，中英双语说明与联动提示；按关卡和具体可用塔、法术过滤，第一关不出现彩色。抽卡与金币概率使用独立随机序列，不修改共享Prefab；退役ID保留兼容但不再随机抽出。
- `BarracksAgent / SoldierAgent`：两名到三名小兵及一名英雄、独立死亡复活计时、互斥的敌人拦截与近战、升级保留生命比例；飞行敌人绕过拦截。
- `LevelSession.Support / LevelSession.Advanced`：冰霜、场景切换、道路集结点、彩色海克斯的延迟效果、免费施法与一次保命；重开清除本局状态。
- `LevelSession.AugmentSynergies`：元素爆发、混合火力、升级与施法收益、军团死亡和治疗联动；按生成代次与全局冷却限制触发，次级伤害不递归触发，重开清理计数与冷却。
- `LevelSession.TowerMastery`：三级寒冰范围冻结的共享控制间隔，以及英雄旋风斩的次级范围伤害。
- `LevelSession.ThirdLevel`：第二关起开放的法术等级与金币升级、第三关限时援军及全军战吼、三关每卡位独立刷新与Boss统计；按关卡开放并在重开时重置。
- `SupportTowerAgent`：按塔等级刷新范围易伤、每秒治疗兵营和法术援军；多塔只取最强易伤。
- `EnemyAgent`：两条偏移车道、转角平行交点、按路径距离移动、剩余路程索敌数据、一次性结算、生成代次、抗性、冰霜与状态清理。
- `TowerAgent / ShotSpec`：塔种配置、两次升级及三级模型切换、转向射击、单体 / 减速 / 范围命中参数。
- `ProjectileAgent`：弹体追踪、颜色区分、一次回池与命中；生成代次防止旧弹伤到复用的新敌人。
- `FireballArea`：火球落地与燃烧范围、固定周期 AOE、回调清场与复用护栏、运行时几何特效。
- `CombatPulse`：炮击、碎冰和升级的短暂扩散圈。
- `GameHud / HudIcon`：TMP SDF 文字、模型 Sprite、矢量资源符号、整体进度、选择与操作反馈、UI 点击阻挡、射程与法术瞄准圈。
- `MapCameraRig`：透视构图随窗口比例调整；外围树林、地面和阴影覆盖画面。

主配置分别在三关各自的 `Gameplay` 对象上；塔数值、升级模型在 `Assets/Game/Prefabs`。编辑器工具 `FirstLevelSetup`、`SecondLevelSetup`、`ThirdLevelSetup` 分别生成对应关卡的资源与配置；`DualRouteSetup` 为现有第一关接入 B 路，`WideRoadSetup` 为三张地图分别生成宽路网格并挖空地面，保留原 palette 与道路石块细节。第三关继续使用雪地风格。运行时不依赖固定地图名称或单条路线。
